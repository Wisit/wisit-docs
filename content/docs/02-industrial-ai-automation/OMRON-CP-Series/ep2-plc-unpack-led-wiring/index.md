## 1. 🎯 ตอนที่ 2: แกะกล่อง PLC: เข้าใจไฟสถานะและจุดเชื่อมต่อ

## 2. 📖 เปิดฉาก (The Hook)
สวัสดีครับพี่น้องสายออโตเมชั่น! เคยมั้ยครับ... โดนโทรตามกลางดึกเพราะเครื่องจักรหยุดกะทันหัน พอเปิดตู้คอนโทรลออกมา สิ่งแรกที่ปะทะสายตาคือ "ไฟ LED สีแดงกะพริบวิบวับ" บนตัว PLC OMRON รุ่นน้องบางคนถึงกับเหงื่อตก ไม่รู้จะเริ่มเช็กจากตรงไหน หรือบางทีแค่ต่อสายกราวด์ผิดจุด เครื่องจักรก็ทำงานรวนแบบผีหลอก (Noise กวนระบบ) ซะงั้น! 

วันนี้รุ่นพี่คนนี้จะมาชงกาแฟ นั่งกางแบบแปลน แกะกล่อง PLC ตระกูล CP Series (CP1E/CP1L/CP1H/CP2E) ให้ดูกันแบบทะลุปรุโปร่ง เราจะมาถอดรหัสภาษาไฟ LED ที่ PLC พยายามจะบอกเรา พร้อมเจาะลึก Layout ของ Terminal Block และ "เคล็ดวิชาการต่อสายกราวด์" ที่ช่างหน้างานมักจะตกม้าตายกันบ่อยๆ รับรองว่าอ่านจบ คุณจะยืนมองหน้าตู้คอนโทรลด้วยความมั่นใจเกินร้อยแน่นอนครับ!

## 3. 🧠 แก่นวิชาออโตเมชั่น (Core Concepts & Specs)
ก่อนจะหยิบไขควงมาขันสายไฟ เราต้องเข้าใจ "ภาษา" ที่ PLC สื่อสารกับเราผ่านไฟหน้าเครื่องกันก่อนครับ สัญลักษณ์ LED บนตัวเครื่อง (Operation Indicators) แบ่งออกเป็นสถานะหลักๆ ดังนี้:

*   **POWER (Green):** ไฟดวงนี้ง่ายสุดครับ ถ้าติดแปลว่ามีไฟเลี้ยงเข้าเครื่องปกติ (Power is ON) ถ้าดับก็เช็กเบรกเกอร์หรือ Power Supply ได้เลย
*   **RUN (Green):** เปรียบเหมือนหัวใจที่กำลังเต้น ถ้าไฟติดแปลว่า PLC กำลังรันโปรแกรม Ladder Logic อยู่ในโหมด `RUN` หรือ `MONITOR` แต่ถ้าไฟดับ แปลว่าเครื่องหยุดรัน (อยู่ในโหมด `PROGRAM`) หรืออาการหนักคือเกิด Fatal Error ครับ
*   **ERR/ALM (Red):** ไฟเตือนภัย! แบ่งระดับความรุนแรงเป็น 2 ระดับ:
    *   **แดงค้าง (Lit):** อาการโคม่า (Fatal Error หรือ WDT Error) PLC จะหยุดทำงานทันที และตัดโหลด Output ทั้งหมดให้เป็น OFF (เซฟตี้โหมด)
    *   **แดงกะพริบ (Flashing):** ป่วยเบาๆ (Non-fatal Error เช่น ฟังก์ชัน FAL ทำงาน) เครื่องยังพอฝืนรันโปรแกรมต่อไปได้ แต่ต้องรีบหาสาเหตุ
*   **INH (Yellow):** ย่อมาจาก Inhibit ถ้าไฟดวงนี้ติด หมายความว่า "Output OFF Bit" (Address `A500.15`) ถูกสั่งให้ทำงาน (ON) ส่งผลให้ Output ทั้งหมดของ PLC ถูกบังคับตัดการทำงาน (OFF) ทันที! มักใช้เวลาทดสอบระบบแบบไม่ต้องจ่ายไฟออกโหลดจริงครับ

## 4. 💻 ร่ายมนต์โค้ดและวงจร (Logic & Wiring)
ทีนี้มาดู Layout ของจุดเชื่อมต่อสายไฟ (Terminal Block) กันบ้าง OMRON ออกแบบมาให้ทำงานง่าย โดยแบ่งโซนชัดเจน:
*   **แผงเทอร์มินอลด้านบน (Top Block):** เป็นโซนของไฟเลี้ยง (L1, L2/N) และขั้วรับสัญญาณอินพุต (Input Terminals) รวมถึงขั้ว Ground
*   **แผงเทอร์มินอลด้านล่าง (Bottom Block):** เป็นโซนของสัญญาณเอาต์พุต (Output Terminals) และถ้าเป็นรุ่นที่ใช้ไฟ AC จะมีขั้วจ่ายไฟ 24 VDC (External Power Supply) แถมมาให้ด้านล่างเพื่อใช้เลี้ยงเซ็นเซอร์ได้ด้วย (สูงสุดประมาณ 300 mA)

มาดูไดอะแกรมการไวริ่งไฟเลี้ยงและกราวด์ที่ถูกต้องกันครับ:

```text
// ------------------------------------------------------------
// [Wiring Diagram: AC Power Supply & Grounding]
// ------------------------------------------------------------
// AC 100-240V -> [ L1 ] [ L2/N ]
//
// Grounding Terminals:
// [ LG ] -> Functional Ground (กรอง Noise)
// [ GR ] -> Protective Ground (กันไฟดูด)

// วิธีจั๊มป์สายสไตล์วิศวกรคุยกัน:
   [ LG ] ----+
              |
   [ GR ] ----+-----> ต่อลงแท่งกราวด์ (Ground Rod)
                      **ต้องมีความต้านทาน < 100 โอห์ม เสมอ!**
                      **ใช้สายไฟขนาด 2 mm^2 ขึ้นไป**

/*
   Comment:
   - ถ้าไฟ AC ฝั่งไหนมีกราวด์มาแล้ว (Grounded Phase) ให้นำเส้นนั้นเข้าขั้ว L2/N
   - ห้ามนำสายกราวด์ของ PLC ไปพ่วงกับโครงเหล็กของอาคาร หรือแชร์ร่วมกับ
     Inverter/Motor ตัวใหญ่ๆ เด็ดขาด! กราวด์ต้องวิ่งตรงลงดิน ไม่งั้น Noise ย้อนกลับรวนทั้งตู้!
*/
```

## 5. 🛡️ เคล็ดลับคนหน้างาน (Factory Floor Pro-Tips)
จากประสบการณ์หน้างาน ผมมีจุดที่วิศวกรและช่างหลายคนมักพลาดมาเตือนกันครับ (อ้างอิงจากคู่มือ Installation Precautions เป๊ะๆ):

1.  **ความลับของ LG และ GR:** `GR` (Protective Ground) มีไว้กันไฟดูด ส่วน `LG` (Line Ground) มีไว้กรองสัญญาณรบกวน (Noise) หากหน้างานมีปัญหา Noise กวนเซ็นเซอร์หนักๆ ให้จับขั้ว LG ชอร์ตเข้ากับ GR แล้วเดินสายกราวด์เส้นเดี่ยว (ความต้านทานต้องน้อยกว่า 100 $\Omega$) ลงดินเลยครับ ช่วยแก้ปัญหาผีหลอกในระบบได้ชะงัดนัก!
2.  **ดึงสติ๊กเกอร์กันฝุ่นออกด้วย!:** เวลาแกะกล่อง PLC ใหม่ๆ ด้านบนของเครื่องจะมีสติ๊กเกอร์ (Label) ปิดช่องระบายอากาศอยู่ หน้าที่ของมันคือ "กันเศษสายไฟและฝุ่น" ตกลงไปในวงจร **ระหว่างการประกอบตู้** แต่เมื่อคุณไวริ่งสายเสร็จหมดแล้ว **ต้องดึงสติ๊กเกอร์นี้ออกทันที!** เพื่อให้เครื่องระบายความร้อนได้ตามปกติ ผมเจอมาเยอะครับ ลืมดึงออกจนเครื่อง Overheat ค้างไปดื้อๆ
3.  **ข้อควรระวังการจ่ายไฟ:** สำหรับรุ่น DC Power Supply เวลาเปิดเครื่องจะมีกระแสกระชาก (Inrush Current) สูงถึง 5 เท่าของกระแสปกติ ดังนั้นเวลาเลือก Switching Power Supply หรือ Breaker ต้องเผื่อพิกัด (Margin) ตรงนี้ไว้ด้วยนะครับ
